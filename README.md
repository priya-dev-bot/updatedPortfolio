# Priyanka Jatoliya | Technical Product Manager Portfolio

A static portfolio built with HTML, CSS and JavaScript. No build step, no dependencies.

## File structure

```
priyanka-portfolio/
├── index.html                      Main page (all sections and case studies)
├── README.md                       This file
├── .nojekyll                       Tells GitHub Pages to serve files as-is
└── assets/
    ├── css/
    │   └── style.css               All styles, light and dark themes
    ├── js/
    │   └── script.js               Page routing, animations, theme toggle
    ├── docs/
    │   └── Priyanka_Jatoliya_Resume.pdf   Resume used by the Download buttons
    └── images/
        └── projects/
            ├── medventure.jpg      MedVenture project screenshot
            ├── ecommerce.jpg       E-commerce Figma design screenshot
            └── restaurant.jpg      Restaurant website screenshot
```

## Publish with GitHub Pages
1. Put these files at the root of a public repository (`index.html` must be on the first screen).
2. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
3. Your site will be at `https://<username>.github.io/<repository>/`.

## Update the resume
Replace `assets/docs/Priyanka_Jatoliya_Resume.pdf` with a new file of the same name, then commit and push.
